Privacy policy

Last updated: 31 October 2026

Argument Forensics is a debate speech analysis tool. This policy explains what the application stores, how it is used, and the choices you have. If someone else runs a copy of this application, that operator is responsible for their own policy and local legal requirements.

1. What we store

  • Account data: email address, an optional display name, a bcrypt password hash, and account timestamps. Plaintext passwords are never stored.
  • Session data: server-side session records in SQLite, referenced by an HttpOnly session cookie. Sessions expire and are deleted on sign-out.
  • Debate content: resolutions, cases, speech text, speech versions, analysis results, findings and argument-graph nodes you create.
  • Technical data: rate-limit counters held in memory, and server logs that record request paths, status codes and errors. Logs do not contain passwords, session tokens, API keys or full speech text.

2. How speech text is processed

When live AI analysis is configured, the speech you submit is sent from the server to the configured model provider (xAI's Grok API by default, or Groq when configured) together with the selected format's rubric and instructions. The provider's own retention and training terms apply to that request. The API key is stored only in the server environment and is never sent to the browser.

When no AI credentials are configured, or demo mode is forced, analysis runs entirely on the server using local rules. In that mode, no speech text leaves the server.

3. What we do not do

  • We do not sell your data.
  • We do not include third-party analytics or advertising trackers.
  • We do not share one user's speeches with another account. Every database query is scoped to the signed-in user.
  • We do not accept file uploads. Only pasted text is accepted.

4. Cookies

Two cookies are used: an HttpOnly session cookie (SameSite=Lax, Secure in production) and a readable CSRF token cookie used to protect state-changing requests. Neither contains your password or your speech text.

5. Retention and deletion

Your cases, speeches, versions, analyses and findings remain until you delete them. Deleting a case removes its speeches and analyses through database cascades. Deleting your account permanently removes your user record, sessions, cases, speeches, versions, analyses, findings and argument-graph data. Deletion is immediate and cannot be undone.

6. Security

The application uses bcrypt password hashing, server-side sessions, CSRF protection, a restrictive Content-Security-Policy, rate limiting, request-size limits, and prepared SQL statements. No system is perfectly secure. Get an independent security review before a public launch.

7. Children

The service is intended for competitive debaters and coaches. It is not directed at children under 13, and accounts should not be created for them.

8. Contact

Privacy questions: privacy@argumentforensics.app. Security reports: security@argumentforensics.app.
