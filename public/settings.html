AI credentials are configured on the server only. Set GROK_API_KEY (xAI), GROQ_API_KEY (Groq), or AI_API_KEY in the server environment, then restart the process. Keys are never sent to the browser, never stored in this database, and never displayed here.

To force local heuristic analysis even when a key exists, set AI_DEMO_MODE=true.
