One report for each debate format

Each format has its own rules. The report uses the right checks for the event you choose.

Public Forum

Two-on-two debate about a current event. Checks contentions, evidence, and weighing.

Lincoln-Douglas

One-on-one value debate. Checks the value, criterion, and philosophical reasoning.

Policy

Plan-based debate. Checks harms, inherency, solvency, disadvantages, and counterplans.

Congressional

Legislative debate. Checks how well the speech explains the bill and answers objections.

World Schools

Three-on-three debate. Checks roles, clash, team consistency, and comparative analysis.

What the report shows

Findings with receipts

Every weakness is tied to the sentence that caused it. You can agree, disagree, or rewrite it.

A map of the argument

See claims, evidence, warrants, impacts, assumptions, and counterarguments, and how they connect.

Revisions you can compare

Save a new version, compare it with the original, and run the report again to see what changed.

How it works

  1. Pick the format, side, and speech type.

    The report uses the rules for that event.

  2. Paste or upload the speech.

    Text, Markdown, Word, and PDF files are read in memory and not stored. The extracted text is sent to the analysis provider only when live AI is enabled.

  3. Read the report.

    You get a summary, a list of findings, and a map of the argument. Each finding cites its passage.

  4. Revise and check again.

    Save a new version and compare it with the original. Run the report again when you are ready.

What is protected

  • Passwords are stored as bcrypt hashes, never as plain text.
  • Each account can only see its own cases, speeches, and reports.
  • Session cookies are HttpOnly and SameSite.
  • Forms use a session-bound CSRF token.
  • SQL queries use bound parameters.
  • Uploads accept text, Word, and PDF files. Files are processed in memory and are not stored.

This is an application under development. Get an independent security review before a public launch.
